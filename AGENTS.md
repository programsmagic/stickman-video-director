## 2. Production Rules (Mandatory for All Agents)

1. **NO SLIDE DECKS OR STATIC PRESENTATIONS**:
   - Never render bullet lists, static text slides, watermarks, or presentation layouts.
   - Every difficult concept must be embodied by a physical analogy or interactive environment.
2. **CHARACTER-FIRST ANIMATION (IK & SPRING PHYSICS)**:
   - Always use 2-bone analytical Inverse Kinematics (`projects/tools/stickman.mjs`) for arms and legs with law of cosines.
   - Characters must hold props, press buttons, look through lenses, and run across stages.
   - Apply harmonic spring physics and hand-drawn line boil for organic life.
3. **MANIM-INSPIRED MATHEMATICAL STRUCTURES**:
   - 3D perspective grids, dynamic coordinate vectors, glowing attention heatmaps, and state machine loops.
4. **PROCEDURAL SYNCHRONIZED FOLEY AUDIO**:
   - Every physical action (laser slicer, typewriter keypress, buzzer beep, chalkboard tap, lightning strike) must have an exact frame-aligned procedural Foley sound effect.
5. **NODE-CANVAS GLYPH SAFEGUARDS**:
   - Standard node-canvas fonts lack emoji and Unicode math symbols (`★`, `🍎`, `❌`, `➔`, `√`).
   - Agents must draw geometric shapes natively on canvas or use standard ASCII equivalents.
6. **FFMPEG CONCAT DEMUXER SYNTAX**:
   - In concat list files, wrap paths in single quotes (`file '/absolute/path/video.mp4'`) to prevent path mangling.
